# Облачное хранилище файлов (Backend)

Backend-приложение для хранения и управления пользовательскими файлами и директориями по модели **S3-совместимого объектного хранилища**.

## Возможности

* Загрузка, скачивание, удаление и перемещение файлов
* Работа с директориями (включая рекурсивные операции)
* Изоляция данных по пользователям
* REST API для frontend-клиента
* Swagger UI для документации API

## Технологический стек

* Java 21
* Spring Boot 3 (Web, Security, Validation)
* MinIO (S3-совместимое объектное хранилище)
* PostgreSQL 
* Redis
* Docker / Docker Compose
* Swagger / OpenAPI
